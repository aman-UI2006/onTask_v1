# 📖 Overview

AI Project Manager is an intelligent project execution platform designed to bridge the gap between **planning** and **execution**.

Unlike traditional project management software that simply stores tasks, AI Project Manager actively assists throughout the project lifecycle by generating workflows, assigning work, monitoring progress, identifying risks, and recommending actions to improve productivity.

The platform is powered by **J.A.R.V.I.S. (Just A Rather Very Intelligent System)**, an AI assistant that helps project managers make faster, smarter, and more informed decisions. :contentReference[oaicite:0]{index=0}

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/yourusername/AI-Project-Manager.git

cd AI-Project-Manager
```

---

## Backend Setup

```bash
cd backend

pip install -r requirements.txt

python app.py
```

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```
